# Demo Script

> Clarify → Build → Edit → Backtrack flow

## 1. Clarify
- User types a request in the prompt box.
- Agent asks one clarifying question with a suggested default.
- User taps the default or answers directly.

## 2. Build
- Agent plans, generates code, and deploys.
- Live URL appears in ~10–20 seconds.
- Decision Timeline populates in real time.

## 3. Share
- Owner shares the link with a teammate.
- Teammate gets OTP-authenticated access (Viewer or Editor).

## 4. Edit
- Owner asks the agent to add a feature via chat.
- App redeploys to the same URL.
- New timeline node appears.

## 5. Backtrack
- Owner opens the Decision Timeline.
- Inspects each step the agent took.
- Reverts to a prior working version if needed.
